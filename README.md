# 🏥 Healthcare Analytics Dashboard

## 📌 Overview
This project is a healthcare analytics dashboard that processes patient data, stores it in PostgreSQL, and visualizes key metrics using Streamlit.

It provides insights into patient trends, hospital performance, and operational metrics.

---

## 🚀 Features
- Patient data ingestion pipeline (CSV → PostgreSQL)
- KPI tracking (patients, revenue, length of stay)
- Department-level analysis
- Diagnosis distribution
- Interactive filters (department, date range)
- Basic authentication system

---

## 🧠 Key Metrics
- Total Patients
- Average Length of Stay
- Total Revenue
- Bed Occupancy Rate
- Admission Trends

---

## 🛠 Tech Stack
- **Python** (Pandas, NumPy)
- **PostgreSQL**
- **SQLAlchemy**
- **FastAPI**
- **Streamlit**
- **Plotly**
